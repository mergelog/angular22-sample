  ```ts

  const b$ = new Subject<string>();
  combineLatest([a$, b$]).subscribe(console.log);

  const a$ = new BehaviorSubject(1); // BehaviorSubject は購読した瞬間に「現在値」を1つ持っているので、combineLatest と相性がいい
  const b$ = new BehaviorSubject('A');

  ```

## Angular

- 左が子、右が親
  ```
    <app-inner-a
      [message]="messageForChild()"          // [message]は子が宣言しているinput.required、messageForChild()は親が宣言したSignal
      [(count)]="count"                      // [(count)]は子のcount、"count"は親のcount
      (messageSent)="receiveMessage($event)" // 子が宣言したoutput、親が持つメソッドreceiveMessage($event)
    />

    [子input]="親signal"
    (子output)="親method"

    // --- sample-06-template-outlet-basic
    // こういう場合もある
    // 子のinput に greeting（つまり<ng-template #greeting>）を渡して、子自体はここで表示（ややこしい）
    <app-sample-06-template-host [content]="greeting" />
    <ng-template #greeting>
     　<p class="greeting">親が渡したメッセージです。</p>
    </ng-template>

  ```

- output と emit はセット

output() を実際に発火させるメソッドが emit()

```
  export class InnerA {
    readonly message = input.required<string>();
    readonly messageSent = output<string>(); // これと
    readonly count = model(0);
  
    sendMessage(): void {
      this.messageSent.emit('子から親への通知です'); // これ
    }
  ```
