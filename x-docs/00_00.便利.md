### ■ショートカット


#### vscodeで、選択範囲を{}の基準で段階的に広げるショートカット
「Expand Selection（選択範囲の拡大）」

macOS:
Control + Shift + Command + →

Windows / Linux:
Shift + Alt + →

#### ターミナル① → ② → ③ のように切り替えるショートカット

macOS:

* 次のターミナル：`Shift + Cmd + ]`
* 前のターミナル：`Shift + Cmd + [`

Windows / Linux:

* 次のターミナル：`Ctrl + PageDown`å
* 前のターミナル：`Ctrl + PageUp`

VS Code公式では `Terminal: Focus Next Terminal` / `Terminal: Focus Previous Terminal` に対応しています。([Visual Studio Code][1])

なお、「ターミナルを横にSplitしている場合」は別です。

* macOS：`Option + Cmd + ← / →`
* Windows / Linux：`Alt + ← / →`

つまり、普通に複数ターミナルを開いてタブ切り替えするなら、Macでは **`Cmd + Shift + [` / `]`** を覚えておけばOKです。

[1]: https://code.visualstudio.com/docs/terminal/basics?utm_source=chatgpt.com "Terminal Basics"
